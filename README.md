# GlobalAnnounce+

GlobalAnnounce+ is a simple Paper 1.19.2 plugin for clean server announcements.

It lets staff send announcements with Minecraft color codes without showing the sender's name.

## Features

- Server-wide announcements
- /at <text> command
- Minecraft color code support, for example &4, &l, &c
- No sender nickname shown in chat
- Configurable default prefix
- Permission support
- Built for Paper 1.19.2

## Command

/at <text>

Example:

/at &4&lALERT&cServer will restart soon!

## Permission

announcement.use

Server operators can use this command by default.
To give this permission to a LuckPerms rank, use: lp group <rank> permission set announcement.use true

## Installation

1. Go to the GlobalAnnounce+ page on Modrinth.
2. Download the version for Paper 1.19.2.
3. Upload GlobalAnnouncePlus.jar to your server's plugins folder.
4. Restart the server.
5. Use /at <text> in game.
